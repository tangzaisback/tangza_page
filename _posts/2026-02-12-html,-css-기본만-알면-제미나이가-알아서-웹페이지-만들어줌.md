update: 이때는 제미나이랑 대화해가며 하나씩 만들고 있었는데, claude code 영업에 넘어가서 이걸 쓰다보니 지금 형태까지 완성 되었다... 정말 천지차이임...세상에... 어떻게 체감하고 있는지 따로 또 정리할 예정!

내 개인 웹사이트를 만들고 싶어서 시도해 본 과정...!

전제는 html, css의 기본을 이해하기 (html의 블록 구조라던가, 정렬방식이라던가, css가 적용되는 방식이라던가..

참고로 내가 html, css 공부한건 논문쓴다고 쓸데없이(?) 실험 페이지 만드느라 2~3일 정도 투자한 정도다.)

그러고 나서 컨셉만 잘 정하면 제미나이가 알아서 해준다.

물론 복붙만으로 만들 수 있는건 아닌데... 어떻게 만드는지 설명하는건 또 천천히 시도해봐야겠다.

제미나이로 하니까 좋은 점은 내가 지시하지 않아도 웹페이지 구성의 기본 문법에 따라 알아서 제안해준다는 점이다.


가령, 글(씨)쓰기 카테고리에 내가 쓴 글들을 게시할거라고 설명하면, 왼쪽 캡쳐와 같이 목록을 구성하고, 마우스가 해당 글 위에 올라가면 회색으로 변하도록 알아서 짜준다. 내가 글 목록을 만들어달라는 구체적 지시를 하지 않아도 이정도 결과가 나온다.

내가 지시한 것은 "텍스트 리스트" 만들라는 것 뿐이었다.
이렇게 해서 짜준 html과 css를 넣고 아주 조금만 수정하면 뚝딱이다~ 세상에~


물론 이렇게 해서 만든 웹사이트는 기본에 충실한 정도지만, 플랫폼을 거치지 않고 내 개인 웹페이지를 소유하고 있다는 것이 마음에 든다.

추후에 내가 공부해서 웹페이지 구조를 효율적으로 만들고, 디자인도 수정하는 것까지 자유도가 열려있다는 것도 장점이다.

우하하. 당분간은 네이버 블로그에 올리겠지만, 조만간 내 웹페이지도 같이 운영하고 싶다는 작은 소망~
